Encryption lab

Test builds only. Checks how this device handles end-to-end encryption before AskLocker uses it. Nothing is sent anywhere. Search downloads a library and a model once, about 35 MB.

1. Locking and unlocking

    
Makes keys, locks a vault key for a member, locks a 5 MB file and 100 passages, and opens them again.

    

    

  


  

    
2. Keeping a key on this device

    
Saves a key the browser will not let anyone read out, opens the page's storage again, and uses it.

    

    

  


  

    
3. Search on this device

    
Loads the search model and times it. The first run downloads about 35 MB.

    

    

  


  

    
3b. Search on the graphics chip

    
The same, on the phone's graphics chip (WebGPU), where it is offered. Downloads another model, about 36 MB.

      The first button uses your AskLocker passkey on this address. The second makes a test passkey called
      "AskLocker lab test (delete me)"; delete it from your password manager afterwards.
